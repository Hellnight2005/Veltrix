Dual-Mode Execution Flow

How bytes flow across the LAN for file drops versus live cinema streams:

FILES Drop Zone → 8 MB Slice Chunks → SHA-256 Checksum → SSE Broadcast → Received Files Center

The Story Behind LocalDrop (Veltrix)

Solving cross-platform file transfers and video streaming with zero cloud dependence.

💡 The Inspiration & The Anime Dilemma

LocalDrop started with a technical blueprint: a Rust-powered P2P file transfer engine with Tokio and streaming SHA-256 to escape cloud relays. But while building it, I ran into a personal frustration: I am a huge anime fan. I download episodes onto my phone, but watching on a tiny screen when a big TV is right there felt limiting. Searching for cables, enabling MTP, and waiting 15 minutes to copy a 3 GB anime episode killed the vibe. Then the breakthrough hit: Why wait for the whole file to transfer before pressing play? What if we stream video slices over the LAN so it plays immediately on the big screen, with exact frame memory?

⚡ The Dual-Engine Breakthrough

That epiphany transformed the project into a dual-engine architecture: 📁 P2P AirDrop File Transfer (78.4+ MB/s, multi-file queue, SHA-256 verification) + 🎬 AirDrop Cinema (HTTP 206 chunked range streaming, <200ms TTFP, and frame-accurate device handoff between phone and TV).

🛠️ How We Built It

The backend engine is engineered in Rust with Tokio asynchronous networking and Postcard binary framing. The presentation layer is a responsive Web PWA with pure CSS/JS, Server-Sent Events (SSE), and a standalone Android APK container.

🧗 Real Technical Hurdles Solved

We resolved the delayed audio echo bug using strict single-audio routing (the phone automatically mutes to act as a silent remote while the TV takes active audio); conquered iOS Safari WebKit autoplay policies with webkit-playsinline and gesture unlocking; and bounded RAM to $O(\text{chunk})$ with zero heap bloat.

🌟 Accomplishments We're Proud Of

Delivering 78.4 MB/s LAN throughput, sub-200ms frame-accurate resume memory, standalone APK v1.0, and 100% peer-to-peer privacy with zero external servers, cloud accounts, or 24/7 battery drain.

🔮 Future Horizons

QUIC transport integration, multi-peer synchronized anime watch parties on the local network, and automatic Wi-Fi Direct peer grouping when no shared router is present.

Deployment & GitHub Pages Guide

How to host this documentation on GitHub Pages and run LocalDrop on your own network.

1

Open Repo Settings

Go to your GitHub repository at github.com/Hellnight2005/Veltrix and click on the Settings tab.

2

Select Pages

In the left-hand sidebar under Code and automation, click on Pages.

3

Set Source to /docs

Under Build and deployment, set Source to Deploy from a branch. Select main or your active branch and folder /docs.

4

Save & Launch

Click Save. In 1–2 minutes, your live site will be live at https://hellnight2005.github.io/Veltrix/!

Run Web & Mobile Cinema App

cd apps/localdrop_web
npm install
npm run dev

Open http://localhost:5173/ for Widescreen Cinema Player, or switch to Mobile Remote on phone view.

Run Rust Core Daemon

cargo run --release -p localdrop_cli -- receive --port 8080 --out ./inbox

Starts high-performance TCP receiver daemon on port 8080 with streaming SHA-256 integrity verification.
