## [Unreleased]

### Planned Milestones
- **v0.1**: Rust TCP Prototype (Proof-of-concept file transfer between two computers using TCP)
- **v0.2**: File Transfer Engine (Large file chunking, resume support, transfer states, and cancellation)
- **v0.3**: mDNS Discovery (Automatic device discovery, device identity registry, manual IP connection)
- **v0.4**: Flutter Desktop UI (Integration with `flutter_rust_bridge` and core UI development)
- **v0.5**: Resume + Integrity (SHA-256 validation and robust interrupted transfer resuming)
- **v0.6**: Security + Pairing (Authenticated connections, pairing flow, and secure transport encryption)
- **v0.7**: Android Support (Permissions, foreground transfer service, and battery optimization)
- **v0.8**: Performance Optimization (Buffered I/O, `mmap` benchmarks, and CPU/RAM optimization)
- **v0.9**: QUIC/UDP Research (QUIC and experimental Custom UDP implementation & comparison)
- **v1.0**: Stable Release (Complete, verified cross-platform release with end-to-end tests)
